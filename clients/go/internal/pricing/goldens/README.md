# Pricing goldens

`ccusage-overrides.json` is generated by the TypeScript collector — it carries a
small catalogue response, the fallback (static) layer, and the ccusage pricing
overrides the TS builder yields for them. The Go client parses the same
catalogue and must reproduce the same map
(`TestCcusagePricingOverridesMatchTheTypeScriptGolden`).

Regenerate after an intentional change to catalogue parsing, the ambiguous-id
collapse, the official anchor, the case-variant aliases, or the above-200k
strip:

```bash
node_modules/.bin/tsx scripts/clients-go-gen-pricing-goldens.mts \
  > clients/go/internal/pricing/goldens/ccusage-overrides.json
```

Never hand-edit the file: the whole point is that TypeScript, not a human,
defines the expected values. CI regenerates both this file and
`internal/contract/goldens/snapshot-hash.json` and fails on any diff, so a
TypeScript-side change cannot land without the Go side being updated to match.
